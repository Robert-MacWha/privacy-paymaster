# Privacy Paymasters

This repo contains implementations of 4337 paymasters for various privacy protocols (Tornado Cash, Railgun). These paymasters are designed
to enable private unshields to new user accounts without needing a trusted per-protocol relayer. Users pay for their transactions using the private assets they hold or are unshielding.

For more information, see the docs in `docs/`. For information on specific protocol implementations, see the relevant subdirectories and docstrings in `contracts/accounts/`.

## Config Management
 - 'config/chains/chain.yaml' - Per-chain config files containing constants.
 - 'config/deployments/chain.json' - Autogenerated per-chain deployment artifacts containing deployed contract addresses.
 - 'secrets/secrets.yaml' - SOPSfile containing private keys, API keys, and other secret material.

## Deployment

```
forge script DeployPaymaster --rpc-url $SEPOLIA_RPC_URL --verifier etherscan --verifier-api-key $ETHERSCAN_API_KEY --verify --broadcast

STAKE_AMOUNT=0 UNSTAKE_DELAY=0 DEPOSIT_AMOUNT=0 forge script StakePaymaster --rpc-url $SEPOLIA_RPC_URL --verifier etherscan --verifier-api-key $ETHERSCAN_API_KEY --verify --broadcast

forge script DeployTornado --rpc-url $SEPOLIA_RPC_URL --verifier etherscan --verify --broadcast
forge script DeployRailgun --rpc-url $SEPOLIA_RPC_URL --verifier etherscan --verify --broadcast
```
